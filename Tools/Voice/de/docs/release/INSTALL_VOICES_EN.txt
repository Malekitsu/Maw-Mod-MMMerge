MAW NPC voices (English) - installation
=======================================

What you get
------------
About 8,500 spoken lines for the people of the game (greetings, topics, news) for MM6, MM7, MM8 and MAW.
Male and female NPCs have different voices. The lines are generated with Kokoro-82M.

You need first
--------------
Might and Magic 8 (GOG) with MMMerge, the patch, Multiplayer and the MAW mod, installed in the order of
the MAW README. The game must start and work. Close the game before you install.

Install (about 670 MB)
----------------------
1. Unzip MAW-Voices-EN-1.0.0.zip into the game folder (the folder that holds mm8.exe).
   Answer "Yes" when Windows asks to merge or replace files.
2. Start the game. Talk to an NPC. The voice plays.

Settings (MAWSettings.lua in the game folder)
* npcVoices      : true / false. Switches the voices on or off.
* npcVoiceVolume : 0.0 to 1.0, relative to the game's sound slider.
* F9 repeats the last voice (press up to 3 times for the ones before), F10 stops it. Both keys can be changed.

If something does not work
--------------------------
* Silence: check npcVoices = true, the Sound slider is not at zero, and the folder Data\Voices\NPC exists.
* Error messages: NPCVoicesLog.txt in the game folder.
* Discord of the MAW mod: https://discord.gg/n59XMtMcnF

Uninstall: delete the files of the package. Nothing else is changed.
